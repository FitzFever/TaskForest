## 开发环境配置

### 必要软件
- Node.js 18+
- npm 或 pnpm
- Visual Studio Code
- Git
- SQLite

### 推荐 VS Code 插件
- ESLint
- Prettier
- TypeScript and JavaScript
- Three.js Editor
- SQLite Viewer
- Git Lens

### 开发命令
```bash
# 安装依赖
pnpm install

# 启动完整开发环境
./start-dev.sh

# 启动前端开发服务器
cd client && pnpm dev

# 启动后端开发服务器
cd server && pnpm dev

# 启动带示例数据的后端服务器
cd server && ./start-with-demo-data.sh

# 运行测试
pnpm test

# 构建应用
pnpm build
```
