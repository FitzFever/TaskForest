# TaskForest示例数据加载指南

本文档说明如何在TaskForest项目中启用和配置示例数据功能。

## 示例数据概述

TaskForest提供了一套预设的示例数据，用于开发和测试环境。示例数据包含：

- 预定义的任务列表
- 与任务关联的虚拟树木
- 各种任务类型和状态示例

## 启用示例数据

### 1. 创建环境变量文件

在`server`目录下创建`.env`文件：

```bash
# 在server目录下
touch .env
```

### 2. 配置环境变量

在`.env`文件中添加以下配置：

```
# 服务器配置
PORT=9000
NODE_ENV=development

# 示例数据配置 - 设置为true以加载示例数据
LOAD_DEMO_DATA=true
```

### 3. 启动开发服务器

使用以下命令启动带有示例数据的开发服务器：

```bash
# 在server目录下
npm run dev:api
```

或者使用项目根目录下的启动脚本：

```bash
# 在项目根目录
./start-dev.sh
```

## 示例数据加载原理

示例数据的加载过程如下：

1. 在`server/src/index.js`中，系统会检查`LOAD_DEMO_DATA`环境变量是否设置为`true`
2. 如果启用，系统会从`server/src/data/devData.js`加载预定义的任务和树木数据
3. 这些数据会被导入到内存数据存储（`dataStore.js`）中

相关代码片段（来自`index.js`）：

```javascript
// 检查是否应该加载示例数据
const shouldLoadDemoData = process.env.LOAD_DEMO_DATA === 'true';

// 将测试数据加载到内存中（仅当环境变量指定时）
if (shouldLoadDemoData && Array.isArray(devTasks) && devTasks.length > 0) {
  logger.info(`正在加载开发环境任务数据，数量: ${devTasks.length}`);
  devTasks.forEach(task => {
    if (!tasks.some(t => t.id === task.id)) {
      tasks.push({...task});
    }
  });
}

if (shouldLoadDemoData && Array.isArray(devTrees) && devTrees.length > 0) {
  logger.info(`正在加载开发环境树木数据，数量: ${devTrees.length}`);
  devTrees.forEach(tree => {
    if (!trees.some(t => t.id === tree.id)) {
      trees.push({...tree});
    }
  });
} else {
  logger.info('跳过加载开发环境示例数据');
}
```

## 自定义示例数据

如需自定义示例数据，可以修改`server/src/data/devData.js`文件，添加或修改任务和树木数据。

## 注意事项

- 示例数据仅建议在开发环境中使用
- 在生产环境中，应该将`LOAD_DEMO_DATA`设置为`false`或不设置
- 示例数据仅保存在内存中，服务器重启后会重新加载
