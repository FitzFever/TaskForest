# TaskForest示例数据加载指南

本文档说明如何在TaskForest项目中启用和配置示例数据功能。

## 示例数据概述

TaskForest提供了一套预设的示例数据，用于开发和测试环境。示例数据包含：

- 预定义的任务列表（包含不同状态、优先级和标签的任务）
- 与任务关联的虚拟树木（包含不同类型和生长阶段）
- 任务树结构和任务间关联关系
- 通知和用户设置示例

## 启用示例数据

### 方法一：使用专用脚本（推荐）

项目提供了专门的启动脚本，可以直接启动带有示例数据的开发服务器：

```bash
# 在server目录下
chmod +x start-with-demo-data.sh
./start-with-demo-data.sh
```

### 方法二：通过环境变量配置

#### 1. 创建环境变量文件

在`server`目录下创建`.env`文件：

```bash
# 在server目录下
touch .env
```

#### 2. 配置环境变量

在`.env`文件中添加以下配置：

```
# 服务器配置
PORT=9000
NODE_ENV=development

# 示例数据配置 - 设置为true以加载示例数据
LOAD_DEMO_DATA=true

# 可选：指定示例数据量级（small, medium, large）
DEMO_DATA_SIZE=medium
```

#### 3. 启动开发服务器

使用以下命令启动带有示例数据的开发服务器：

```bash
# 在server目录下
pnpm dev
```

### 方法三：通过命令行参数

也可以直接通过命令行参数启动带有示例数据的服务器：

```bash
# 在server目录下
LOAD_DEMO_DATA=true DEMO_DATA_SIZE=large pnpm dev
```

## 示例数据内容

当前版本的示例数据包含以下内容：

1. **任务示例**：
   - 工作类任务（项目报告、会议准备等）
   - 学习类任务（阅读文章、学习课程等）
   - 生活类任务（购物、运动、娱乐等）
   - 包含不同优先级、状态和截止日期

2. **树木示例**：
   - 不同类型的树木（橡树、松树、樱花树等）
   - 不同生长阶段的树木（幼苗、小树、成熟树等）
   - 不同健康状态的树木

3. **任务树示例**：
   - 项目拆解示例（主任务+子任务结构）
   - 多级任务层次结构
   - 任务间依赖关系

4. **用户设置示例**：
   - 界面偏好设置
   - 通知设置
   - 3D场景设置

## 示例数据加载原理

示例数据的加载过程如下：

1. 在`server/src/index.js`中，系统会检查`LOAD_DEMO_DATA`环境变量是否设置为`true`
2. 如果启用，系统会从`server/src/data/devData.js`加载预定义的数据
3. 系统会根据可选的`DEMO_DATA_SIZE`环境变量决定加载数据的数量
4. 这些数据会被导入到内存数据存储或数据库中

相关代码片段：

```javascript
// 检查是否应该加载示例数据
const shouldLoadDemoData = process.env.LOAD_DEMO_DATA === 'true';
const demoDataSize = process.env.DEMO_DATA_SIZE || 'medium';

// 将测试数据加载到存储中
if (shouldLoadDemoData) {
  logger.info(`正在加载开发环境示例数据, 数据量级: ${demoDataSize}`);
  
  // 加载示例数据
  const { tasks, trees, taskTrees, settings } = loadDemoData(demoDataSize);
  
  // 导入任务数据
  importDemoTasks(tasks);
  
  // 导入树木数据
  importDemoTrees(trees);
  
  // 导入任务树数据
  importDemoTaskTrees(taskTrees);
  
  // 导入设置数据
  importDemoSettings(settings);
  
  logger.info('示例数据加载完成');
} else {
  logger.info('跳过加载开发环境示例数据');
}
```

## 自定义示例数据

如需自定义示例数据，可以修改以下文件：

- `server/src/data/demoTasks.js` - 任务示例数据
- `server/src/data/demoTrees.js` - 树木示例数据
- `server/src/data/demoTaskTrees.js` - 任务树示例数据
- `server/src/data/demoSettings.js` - 设置示例数据

## 高级配置

### 数据量级控制

示例数据提供三种量级：

- `small`: 约10个任务和树木，适合快速测试
- `medium`: 约50个任务和树木，适合一般开发（默认）
- `large`: 约200个任务和树木，适合性能测试

通过环境变量设置：

```
DEMO_DATA_SIZE=large
```

### 数据持久化

默认情况下，示例数据仅保存在内存中，服务器重启后会重新加载。如果需要将示例数据持久化到数据库，可以使用：

```
DEMO_DATA_PERSIST=true
```

## 注意事项

- 示例数据仅建议在开发环境中使用
- 在生产环境中，应该将`LOAD_DEMO_DATA`设置为`false`或不设置
- 示例数据可能会影响性能测试结果，进行性能测试时应注意数据量
- 如果需要清除示例数据，可以使用`npm run clear:demo`命令（需要服务器重启）
